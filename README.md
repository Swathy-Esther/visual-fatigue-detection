# Visual Fatigue Detection System
A deep learning project using a custom CNN to analyze visual fatigue through eye tracking, yawning, and posture.

## About the Project
This project aims to detect signs of visual fatigue by monitoring three key metrics:
1. **Eyes:** Detecting blink rates and eye closure.
2. **Yawn:** Identifying yawning patterns.
3. **Posture:** Analyzing head tilt or slumping.

## Project Structure
The project is organized into modular components for data, models, and UI.
